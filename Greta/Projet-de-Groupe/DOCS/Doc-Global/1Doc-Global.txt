Vue d'ensemble du projet
ClickTalk est une application de chat intelligent permettant aux utilisateurs de communiquer avec un assistant IA tout en organisant leurs conversations par projets. L'application offre une interface intuitive, réactive et moderne avec un design soigné, supportant à la fois les thèmes clair et sombre.

Objectifs principaux :

Fournir une interface de chat fluide pour interagir avec l'IA
Permettre l'organisation des conversations par projets thématiques
Offrir une expérience utilisateur optimale sur tous les appareils
Assurer la sécurité des données utilisateurs
Architecture technique
Stack complète
🌐 Frontend
Framework principal : React 18 avec TypeScript
Styles : SASS avec architecture modulaire
Routing : React Router v6
Gestion d'état : Context API
Tests : Jest & React Testing Library
🖥️ Backend
Framework : Spring Boot (Java)
Base de données : MySQL
Authentification : Spring Security & JWT
API : REST avec endpoints standardisés
🛠️ Outils de développement
Versioning : Git & GitHub
Test API : Postman & Swagger
Linting : ESLint & Prettier
Build : Maven (backend), npm/yarn (frontend)
🎨 Design
Maquettes : Figma (lien maquettes)
Collaboration : Miro (tableau de conception)
Responsive : Mobile-first avec breakpoints stratégiques
Design System : Jeu de couleurs, typographie et composants standardisés
🚀 Déploiement
Frontend : Vercel
Backend : AWS/Heroku/Docker
CI/CD : GitHub Actions
Monitoring : Sentry/Datadog

Structure de la base de données
Tables principales
Users : Informations des utilisateurs

API Endpoints
Authentification
POST /api/auth/register : Inscription
POST /api/auth/login : Connexion
POST /api/auth/refresh : Rafraîchissement du token
DELETE /api/auth/revoke : Déconnexion
Utilisateurs
GET /api/users/me : Profil de l'utilisateur connecté
PUT /api/users/me : Mise à jour du profil
DELETE /api/users/me : Suppression du compte
Projets
GET /api/projects : Liste des projets
POST /api/projects : Création d'un projet
GET /api/projects/{id} : Détails d'un projet
PUT /api/projects/{id} : Mise à jour d'un projet
DELETE /api/projects/{id} : Suppression d'un projet
Conversations
GET /api/conversations : Liste des conversations
POST /api/conversations : Création d'une conversation
GET /api/conversations/{id} : Détails d'une conversation
DELETE /api/conversations/{id} : Suppression d'une conversation
Messages
GET /api/conversations/{id}/messages : Messages d'une conversation
POST /api/conversations/{id}/messages : Envoi d'un message
DELETE /api/messages/{id} : Suppression d'un message

Flux utilisateur
Parcours d'inscription/connexion
L'utilisateur arrive sur la page d'accueil
Il s'inscrit ou se connecte via le formulaire
Après authentification, il est redirigé vers l'interface principale
Création d'un projet
L'utilisateur clique sur "Nouveau projet" dans la sidebar
Il remplit le formulaire avec titre et instructions personnalisées
Le projet est créé et apparaît dans la liste des projets
Conversation avec l'IA
L'utilisateur sélectionne une conversation existante ou en crée une nouvelle
Il saisit un message dans l'input et l'envoie
L'IA répond avec un streaming de texte en direct
La conversation se poursuit et est sauvegardée automatiquement

Guide de déploiement
Prérequis
Node.js 16+
Java 17+
MySQL 8+
Git
Déploiement Frontend
Cloner le dépôt
Installer les dépendances : npm install
Configurer les variables d'environnement dans un fichier .env
Build du projet : npm run build
Déployer les fichiers statiques générés (dossier build/) sur Vercel ou autre service d'hébergement
Déploiement Backend
Cloner le dépôt
Configurer les propriétés de l'application dans application.properties
Build du projet : mvn clean install
Déployer le JAR généré sur le serveur (AWS, Heroku, etc.)
Configurer la base de données et les variables d'environnement
